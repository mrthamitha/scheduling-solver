# Scheduling Solver — CPU & Disk Scheduling Visualiser

A full-stack tool for learning CPU and disk scheduling: Gantt charts, per-process
tables and step-by-step traces explaining every scheduling decision.

**Status:** 🚧 Work in progress — backend under construction.

## Tech stack
- Backend: Node.js + Express (REST API)
- Frontend: React + Vite (coming soon)
- Database: SQLite (planned)

## Run locally
```bash
cd server
npm install
npm run dev     # http://localhost:4000/api/health
